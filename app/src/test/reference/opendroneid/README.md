# Independent Remote ID reference fixtures

`fixture_generator.c` encodes the constants in
`../../java/app/fieldwatch/domain/OpenDroneIdReferenceFixtures.kt` with the
independent [OpenDroneID core C library](https://github.com/opendroneid/opendroneid-core-c/tree/849c03adbe0cdd68997a462fafab397edcfe53f3).
It calls the reference Basic ID, Location, System, and Message Pack encoders;
it does not construct payloads using Fieldwatch's decode offsets.

Reference commit: `849c03adbe0cdd68997a462fafab397edcfe53f3`.
The header declares protocol version 2 and message size 25 bytes.
The upstream reference C library is Apache-2.0; it is fetched for regeneration
and is not vendored into the app.

Expected SHA-256 values:

- `opendroneid.c`: `60b0964f5f2a0dc13833eb6a304f7bd3f64bb9c227fae168c7caba53c82927c2`
- `opendroneid.h`: `a60b9b38c4fa82d7c85437dc11f57f0dea4ebf8bb4b90b3ff3c21c585ccd55f4`

Run from the repository root, with a C11 compiler and curl installed:

```sh
rid_reference_dir="$(mktemp -d)"
rid_reference_commit=849c03adbe0cdd68997a462fafab397edcfe53f3
curl --fail --location "https://raw.githubusercontent.com/opendroneid/opendroneid-core-c/$rid_reference_commit/libopendroneid/opendroneid.c" --output "$rid_reference_dir/opendroneid.c"
curl --fail --location "https://raw.githubusercontent.com/opendroneid/opendroneid-core-c/$rid_reference_commit/libopendroneid/opendroneid.h" --output "$rid_reference_dir/opendroneid.h"
shasum -a 256 "$rid_reference_dir/opendroneid.c" "$rid_reference_dir/opendroneid.h"
clang -std=c11 -Wall -Wextra -I "$rid_reference_dir" app/src/test/reference/opendroneid/fixture_generator.c "$rid_reference_dir/opendroneid.c" -lm -o "$rid_reference_dir/generate-fixtures"
"$rid_reference_dir/generate-fixtures"
```

Tests add transport framing separately: BLE FFFA service data includes the
`0D` application code, counter, and encoded message or pack. The Wi-Fi vendor
IE parser has already removed OUI `FA:0B:BC` and type `0D`, so its `dataHex`
starts with the counter. A Wi-Fi counter of `0D` remains a counter.

These fixtures check decoding and state updates. They do not establish radio
range, reception compatibility, drone identity, or physical detection rates.
